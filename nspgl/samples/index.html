nspGL demos

WebGL & HTML on a TI-Nspire CX. Press tab to pick a link, enter to open, esc to go back, menu for options.

  • Spinning cube — vertex colors, depth test
  • Plasma shader — fullscreen fragment shader
  • Textured quad — texture from a 2D canvas
  • Lit torus — per-vertex lighting, drawElements
  • 2D canvas — shapes and text
  • Raymarcher — loops & functions in GLSL (slow)
  • three.js r149 — PBR material, texture, points (takes a few seconds to load)
  • Keyboard demo — arrow keys and touchpad

Rendering is done in software by a GLSL interpreter, so keep shaders small.
